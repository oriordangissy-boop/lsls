# 时计 TIMEPIECE — 腕表展示网站

可直接导入 Git 的静态网站，不需要安装前端依赖。页面、图片、字体回退与二维码生成均可本地运行。

## 已完成

- 参考 Tonino Lamborghini 腕表目录的黑色导航、商品横幅、白底陈列与侧栏筛选。
- 14 款销售方腕表图，重新按原始资料表坐标提取；不含代理价栏。
- 系列与颜色交叉筛选、清除筛选、排序、全站搜索。
- 独立款式页、同系列颜色切换、图片放大、商品信息和人民币销售方公示价。
- 1000 个独立编号、1000 个固定随机链接，扫码显示此枚序号与该款限量。
- 完整编号查询、超额/无效编号拒绝；兼容原款式公用链接。
- 70 × 40 mm 价格标签：选择款式与具体枚号、本地 QR 生成、SVG 下载和补印。
- 商品图保留原始细节，使用 CSS 裁切资料表杂边，统一陈列背景；未采用会改变表盘细节的 AI 修饰图。
- 手机布局、键盘操作、对话框关闭、低动态效果支持。

## 打开与运行

最简单：双击 `start-site.cmd`，按窗口提示访问本机地址。
也可以安装 Node.js 后在项目目录运行：

```sh
npm start
```

打开 http://127.0.0.1:8080/ 。关闭终端即停止本地服务器。

也支持双击 index.html 直接浏览；本地文件模式下，标签工作台需填写已部署的 HTTPS 网站地址。

## 页面入口

- 首页：`index.html`
- 蓝色镂空款：`index.html?sku=ZY-3038LB.01`
- 查询：`index.html?page=lookup`
- 售后资料：`index.html?page=service`
- 标签：`label.html`
- 单表示例：`?v=RAIKOHy-4CNtMEosnu0XTA`（ZY-3038LB.01-01）
- 每枚完整编码和 token 见 `data/units.js`。历史 m7qa 开头的样张仍保留样张说明，不用于正式贴牌。

## 部署到 Git 静态托管

把整个目录作为仓库内容上传。无构建命令，发布目录为仓库根目录。
可使用支持静态文件的 GitHub Pages、Cloudflare Pages、Netlify 或其他托管。

部署后在 data/registry.js 设置：
- PASSPORT_CONFIG.publicBaseUrl：完整 HTTPS 站点地址（含项目子目录），以斜杠结尾。
- 页面运营名称与售后资料：替换实际销售主体。
- 价格、日期和图片：按真实商品资料维护。

标签工作台也支持直接输入站点地址。先部署，再生成正式标签，最后用手机实扫。
本机 127.0.0.1 地址只适用于本电脑检查，不能印给客户。
打印选 70 × 40 mm、100% 比例，关闭页眉页脚。

## 数据范围

本版收录 14 个款式，已按销售方更正资料签发 1000 个独立编码及随机 token。
ZY-3035LB.01 / .02 / .03 的限量分别更正为 70 / 80 / 50 枚；其他款保持原数量，总计 1000 枚。
每款以 01 起顺序编号，例如 ZY-3038LB.04-01 至 ZY-3038LB.04-100。
这是销售方编号签发，不是已经完成的实物绑定；`physicalBinding: pending` 如实保留，须在出库时逐只核对表背/保卡/吊牌。
**不可重新生成、替换或打乱已签发的 token 与 serial 对应关系，否则会破坏已打印吊牌。**
`data/units.js` 是公网编号注册表，需要备份；随机 token 不是保密凭证，不是鉴定或防伪技术。
静态文件不提供登录后台、数据库、鉴定或防复制能力。

商品照片来自用户提供的低分辨率资料表。提取改善了构图，没有生成不存在的细节；高清商品页需换成实拍原图。
商品统一展示“销售方公示价 ¥49,999”，并未核实为品牌官方价格。
“经典钢带”仅为本站展示分类，不代表已验证防水等级、机芯或材质。
